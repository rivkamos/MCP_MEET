# 🧠 LangChain + LangGraph Demo

## מה אנחנו בונים?
מערכת AI שיכולה:
- להבין שאלות
- להשתמש בכלים (Tools)
- להחזיר תשובות חכמות

---

## 🧩 מה זה LangChain?

LangChain הוא כלי שמאפשר לחבר:
- מודלים (כמו Gemini)
- פונקציות (Tools)
- זיכרון ולוגיקה

במילים פשוטות:
👉 "דרך לבנות אפליקציות סביב AI"

---

## 🧠 מה זה LangGraph?

LangGraph מוסיף דבר חשוב:

👉 במקום שיחה פשוטה
👉 אנחנו בונים גרף של צעדים

כלומר:
- לחשוב
- להחליט
- להשתמש בכלי
- להמשיך לחשוב

---

## 🔧 מה זה Tool?

Tool הוא פונקציה שה-AI יכול להפעיל.

בדוגמה:
get_meetings() → מחזיר פגישות מקובץ

---

## 🔄 איך המערכת עובדת?

User → Agent → LLM → Tool → LLM → Answer

---

## 🎯 מטרת הדמו

להראות:
- AI לא רק עונה
- הוא גם משתמש בכלים
- הוא פועל כמו "סוכן חכם"
